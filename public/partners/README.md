# Logos de seguradoras (carrossel do footer)

## Uso
- Lista: `src/content/partners.ts`
- Carrossel: `PartnerCarousel` no `SiteFooter`

## Arquivos oficiais
Substitua cada SVG por **artes aprovadas** pelo comercial/jurídico (press kit, portal de parceiros ou manual de marca). Mantenha o **mesmo nome de arquivo** ou atualize `logoSrc` no `partners.ts`.

## Estado atual
Os SVGs em `/public/partners/` seguem **cores e wordmarks públicos** das marcas para layout fiel no demo. Para produção, troque pelos arquivos oficiais (preferência: SVG ou PNG @2x fundo transparente).

## Nuviora
Sem associação de marca até contrato de distribuição formal.
